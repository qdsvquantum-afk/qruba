# Contributing To Qruba Public Docs

This repository is a public product page and documentation space for Qruba.

## Good Contributions

- Documentation corrections.
- Better explanations for users.
- Public example ideas.
- Case-study improvements.
- Screenshots, diagrams or wording improvements.
- Reports of confusing product copy.

## Out Of Scope

- Requests for private QDSV Runtime source code.
- Infrastructure secrets or deployment credentials.
- Private customer data.
- Production backend internals.
- Claims of guaranteed quantum advantage.

## Reporting Issues

Please include:

- page or section;
- what confused you;
- suggested correction;
- whether the issue is business-facing, developer-facing or expert-facing.
