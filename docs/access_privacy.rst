Access and Privacy
==================

Access
------

* Qruba Cloud: https://cloud.qruba.site/
* Private Docker access: https://qruba.site/ when the private node is
  available.
* QDSV model site: https://qdsv.cloud/

Public project scope
--------------------

The public repository is a product page and documentation space for Qruba. It
does not include:

* private QDSV runtime;
* Qruba platform source code;
* CAP internals;
* backend orchestration;
* lowering logic;
* QuEST/Aer/IBM adapters;
* infrastructure secrets;
* production configuration;
* proprietary execution components.

Data posture
------------

Qruba is designed around prepared data and auditable workflows. Sensitive,
large, regulated or private workloads should use the appropriate licensed
cloud or private Docker deployment.
