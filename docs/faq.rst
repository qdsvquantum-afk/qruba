FAQ
===

Does Qruba replace Qiskit, Braket or other quantum SDKs?
--------------------------------------------------------

No. Qruba sits earlier in the workflow. It helps users express and audit the
problem before backend-specific execution or circuit materialization is needed.

Does Qruba guarantee quantum advantage?
---------------------------------------

No. Qruba is a visual semantic-computation platform. It can support logical,
simulated, statevector and hardware-capable routes depending on configuration,
but it does not claim guaranteed quantum advantage.

Does the public repository include the platform source code?
------------------------------------------------------------

No. The public repository is a product and documentation space. Private runtime
and orchestration components are not included.

Where should users start?
-------------------------

Start with Qruba Cloud for the hosted product, or use the private Docker demo
when the local/private node is available.
