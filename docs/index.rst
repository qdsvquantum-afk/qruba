Qruba
=====

Qruba is the visual semantic computation platform powered by **QDSV - Quantum
Declarative Semantic Value**.

It helps users build auditable workflows from prepared data, problem intent,
predicates, rankings, reliability policies and evidence without forcing them
to start by designing quantum circuits.
