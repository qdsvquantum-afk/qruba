# Qruba Public Roadmap

Qruba is the visual platform powered by QDSV. This public repository documents the product, its scope and public examples. It does not include the private platform source code.

## Current

- Qruba Cloud access.
- Private Docker access when the private node is available.
- Visual workflow builder.
- Prepared CSV/JSON input.
- Predicate / Oracle node.
- Semantic Operation node.
- Decision Model node.
- Combinatorial Search node.
- QIntent node and QDSV Console.
- Output and Trace / Verification nodes.
- Experimental Semantic AI, Crypto QDSV and Sensing Evidence nodes.
- Reliability, noise and decision-layer reporting.

## Next

- Cleaner public getting-started material.
- More public screenshots and short demo clips.
- More case-study summaries.
- Clearer distinction between semantic decision and hardware evidence.
- More user-facing guides by audience: business user, data team, developer, quantum expert.

## Later

- Marketplace packaging exploration.
- More public pilots and case reports.
- Expanded QIntent/Bridge integration examples.
- More onboarding paths for Community, pilots and enterprise evaluation.

## Boundaries

Qruba public materials should not present experimental crypto as production cryptography, sensing experiments as certified hardware sensing, or hardware evidence as guaranteed quantum advantage.
